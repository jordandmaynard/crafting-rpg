# Empty potion bottle and bone dust

Two painterly RPG item icons, each an RGBA PNG at exactly 256×256 pixels with alpha values restricted to 0 and 255.

- `empty-potion-bottle-painterly-256x256.png`: empty rounded glass bottle with a brown cork stopper. The glass is illustrated with pale blue reflections inside an opaque body so the final alpha remains binary.
- `bone-dust-painterly-256x256.png`: ivory bone powder with a partly buried skull cap and upper eye sockets to make the material recognizable.

Preserve alpha and square aspect ratio on import. Use texture filtering/mipmaps for smaller display sizes. No border, UI background or cast shadow is baked in. The preview includes each item at 72px for legibility review.

Created with built-in image generation. Art direction: dimensional painterly resource items matching the approved glass pane and bone stack, centered three-quarter presentation, clean silhouette, no scenery or labels. Source artwork was cropped, resized with Lanczos and alpha-thresholded at 128.
