# Crafting table building icons — painterly 256×256

Three standalone RGBA PNGs:

- `build-weapon-crafting-table-painterly-256x256.png`: oak workbench with anvil, sword, arrows and upright weapon shafts.
- `build-armor-crafting-table-painterly-256x256.png`: oak workbench with leather armor cutting pattern, thread spool and shears.
- `build-alchemy-table-painterly-256x256.png`: oak workbench with raised bottle shelves, corked bottles, mortar and pestle, candle and jars.

Each icon is exactly 256×256 with alpha values restricted to 0 or 255. Preserve alpha and square aspect ratio on import; use mipmaps/texture filtering for smaller UI sizes. The preview includes 72px examples. These build menu illustrations follow the established classic 2:1 isometric visual direction and painterly building style. They are not tileable world geometry.

Created with built-in image generation using each in-game screenshot for the layout and the approved painterly saw table for materials and presentation, then cropped, resized with Lanczos, and alpha-thresholded at 128.
